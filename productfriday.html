Why local

Sensitive material never has to leave the machine to be processed

Cloud agents require uploading the very material that is most sensitive: contracts, patient notes, unpublished financials. The result is that the highest-value automation is the least permitted.

What is Friday?+

Friday is a local device agent, in development. It runs on an employee's own machine, works across their local files and applications, completes multi-step tasks, and shows each result for approval before anything is acted on.

Why run an agent locally instead of in the cloud?+

Because the material worth automating is usually the material that must not be uploaded. Running on the device means contracts, records and unpublished figures do not have to leave the machine to be worked on.

Does Friday send data anywhere?+

It is designed so that it does not have to. Where a task needs a capability the device does not have, the request is explicit rather than automatic.
